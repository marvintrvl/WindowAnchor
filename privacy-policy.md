# Privacy Policy

## Overview

WindowAnchor Browser Connector is a browser extension designed to save and restore the user’s browser tabs and tab groups as part of a WindowAnchor workspace session.

This extension is intended to help users preserve their browser context when switching between desktop workspaces. It does not collect, sell, or share personal data with third parties.

## What data the extension uses

The extension may read the user’s currently open tabs and tab group information so that the user can save and restore their browser state with their WindowAnchor workspace.

This may include:
- tab titles
- tab URLs
- tab group information
- browser session state needed to restore the current workflow

This data is used only to:
- save the current browser state
- restore the browser state later
- support the user’s local WindowAnchor workflow

## Where the data goes

The extension communicates with the user’s local WindowAnchor desktop application through native messaging.

The data is used locally on the user’s device to support saving and restoring workspace browser state. It is not sent to a remote server for tracking, advertising, analytics, or any unrelated purpose.

## No remote code

This extension does not use remote code execution. It does not download or execute code from a remote source. It runs locally in the browser and communicates with the local WindowAnchor application installed on the user’s device.

## No data collection for advertising or analytics

This extension does not:
- collect personal identifiers
- track browsing activity for advertising purposes
- sell user data
- share data with third parties
- use analytics or advertisement networks
- use location tracking, account data, or payment data

## Data retention

The extension stores browser session data only as needed for the user’s local WindowAnchor workspace save and restore functionality. Data is not retained for marketing, profiling, or unrelated business purposes.

## Changes to this policy

This privacy policy may be updated from time to time. Continued use of the extension after an update means the user accepts the revised policy.

## Contact

For privacy questions or support, contact the publisher through the contact email listed in the Chrome Web Store item settings.
